# Карта модуля shef.toolsaiannounce

> Последняя сверка: 2026-10-16

## Цель

«Новинки для сотрудников» отдельным модулем: любой модуль присылает свои
объявления событием, администратор правит их на одной странице, сотрудник
видит каждое один раз.

## Состояние

| что | версия | статус |
|---|---|---|
| Вынос из shef.toolsai: окно, аудитория, отметки | 1.0.0 | 🧪 тесты; на портале не проверено |
| Событие `OnAnnouncementsCollect`, слияние, лог конфликтов | 1.0.0 | 🧪 |
| Страница списка, права R/W, пункт меню | 1.0.0 | 🧪 |
| Перенос настроек и отметок из shef.toolsai | 1.0.0 | 🧪 |

## Что в работе

* `shef.toolsai`: убрать свои новинки, присылать «ИИ в звонках» событием,
  снять старый обработчик `main:OnEpilog` (ветка `claude/split-modules` там).
* Выкладка на портал клиента — по слову владельца, сначала этот модуль.
