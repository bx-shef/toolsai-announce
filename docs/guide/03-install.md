# Установка и права

> Последняя сверка: 2026-10-17 (1.2.0)

## Зависимости

* `shef.options` 3.0+ — страница настроек;
* `shef.problems` 2.0+ — лог конфликтов.

От `shef.toolsai` модуль **не зависит**: ни при установке, ни в работе.
PHP 8.2+, главный модуль 22.600.300+, портал в UTF-8.

## Что делает установка

1. Регистрирует модуль, сбрасывает кеш списка.
2. Пишет заглушку `/bitrix/admin/shef_toolsaiannounce_list.php` — путь туда, где
   модуль стоит на самом деле (`/bitrix/modules` или `/local/modules`). Чужой
   файл на её месте не трогает и пишет об этом в форме.
3. Подписка `main:OnEpilog` → `OnEpilogEventHandler::handle()` (из
   `installEvents` в `.settings.php`; повторная установка не плодит дублей).
4. Подписка `shef.toolsai:OnViewSettingsMenuBuild` →
   `Internals\Integration\ToolsAi\EventHandler\OnViewSettingsMenuBuildEventHandler::handle()`
   (1.4.1): пункт «Оповещения для сотрудников» в меню шестерёнки вида «ИИ»
   shef.toolsai 1.53+ — ссылка на страницу списка, только при праве на модуль
   от R. Нет shef.toolsai или он старше — событие никто не шлёт.
5. Подписка старого вида (`isCompatible`) `rest:OnRestServiceBuildDescription` →
   `Integration\Rest\Service::onRestServiceBuildDescription()` (1.5.0):
   REST-методы `shef.announce.*` в области `shef_announce` для MCP-сервера —
   [04-mcp.md](04-mcp.md).

**Обновление копированием файлов** (установщик не запускается, 1.4.1): на
первом хите после смены версии `OnEpilogEventHandler` зовёт `Main\Maintenance`,
и тот ставит подписки из `installEvents` (повтор безвреден — ядро не плодит
дублей). До какой версии довели — опция `SYS_eventsversion`.

**Перенос из `shef.toolsai` убран в 1.2.0.** На обоих порталах модуль уже
стоит, настройки и отметки перенесены установкой 1.0.x–1.1.0. Установка 1.2.0
не читает данные `shef.toolsai` и не снимает его старый обработчик
`main:OnEpilog`. Ставить модуль заново на портал со старым `shef.toolsai`
(до 1.50.0) — только через 1.1.0.

## Права

Уровни модуля («Настройки → Настройки модулей → [SH] Оповещения для сотрудников →
Доступ»):

* `R` — видеть страницу списка и «Показать мне снова»;
* `W` — править список и настройки.

Администратор портала — всегда `W`. Отметку «видел» сотрудник ставит только
себе (`shef:toolsaiannounce.banner.seen`: POST, sessid, авторизация).

## Удаление

Проверка: модуль не удалится, пока его требует другой модуль
(`requireModules`). Снимаются заглушка (только своя) и подписки
`main:OnEpilog` и `shef.toolsai:OnViewSettingsMenuBuild`. Без `savedata`
удаляются настройки модуля и отметки «видел».
