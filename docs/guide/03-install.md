# Установка, перенос, права

> Последняя сверка: 2026-10-16 (1.0.1)

## Зависимости

* `shef.options` 3.0+ — страница настроек;
* `shef.problems` 2.0+ — лог конфликтов.

От `shef.toolsai` модуль **не зависит**: ни при установке, ни в работе.
PHP 8.2+, главный модуль 22.600.300+, портал в UTF-8.

## Что делает установка

1. Регистрирует модуль.
2. **Перенос из shef.toolsai** (если тот стоял):
   * настройки `ANNOUNCE_list` и `ANNOUNCE_testusers` — только если свои не
     сохранены или пусты; значение копируется как есть;
   * отметки «видел» всех пользователей (личная настройка `shef.toolsai` /
     `announce_seen`) объединяются со своими — без повторов, не больше 200.
   Данные `shef.toolsai` не удаляются. Повторная установка ничего не портит.
   Итог — строкой в форме после установки.
3. Пишет заглушку `/bitrix/admin/shef_toolsaiannounce_list.php` — путь туда, где
   модуль стоит на самом деле (`/bitrix/modules` или `/local/modules`). Чужой
   файл на её месте не трогает и пишет об этом в форме.
4. Подписка `main:OnEpilog` → `OnEpilogEventHandler::handle()` (из
   `installEvents` в `.settings.php`; повторная установка не плодит дублей).

5. Снимает старый обработчик новинок `shef.toolsai` (`main:OnEpilog` →
   `Shef\ToolsAi\Announce\Events::onEpilog`, класс с ведущим «\» и без):
   на `shef.toolsai` старше 1.50.0 окно иначе пришло бы дважды (с 1.0.1).

**Рекомендуемый порядок выкладки:** сначала `shef.toolsai` 1.50.0 (в нём
своих новинок нет, объявление «ИИ в звонках» он присылает событием), затем
этот модуль. Если этот модуль ставится раньше — он сам снимет старый
обработчик `shef.toolsai`, но до обновления `shef.toolsai` объявление «ИИ в
звонках» не придёт: старый `shef.toolsai` события не шлёт.

⚠ В `shef.toolsai` пустой список означал «объявление по умолчанию». Теперь
объявления по умолчанию присылают модули событием; если в `shef.toolsai` список
был сохранён пустым (`[]`), после переноса объявление `shef.toolsai` всё равно
придёт — выключите его своей копией на странице списка.

## Права

Уровни модуля («Настройки → Настройки модулей → [SH] Новинки для сотрудников →
Доступ»):

* `R` — видеть страницу списка и «Показать мне снова»;
* `W` — править список и настройки.

Администратор портала — всегда `W`. Отметку «видел» сотрудник ставит только
себе (`shef:toolsaiannounce.banner.seen`: POST, sessid, авторизация).

## Удаление

Проверка: модуль не удалится, пока его требует другой модуль
(`requireModules`). Снимаются заглушка (только своя) и подписка
`main:OnEpilog`. Без `savedata` удаляются настройки модуля и отметки «видел».
