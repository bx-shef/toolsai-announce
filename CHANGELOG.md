# История изменений

## 1.3.0 — 2026-10-17

* Страница списка оформлена штатными UI Битрикс24, как страницы
  `shef.toolsai`: пояснения — `ui.alerts`, кнопки — `ui.buttons` (основная
  «Сохранить», второстепенные «Изменить», «Показать мне снова» с подсказкой
  `ui.hint`, «Удалить»/«Вернуть как в модуле» — красная, с подтверждением),
  поля формы — `ui.forms` с подписями, «Откуда», «Кому», «Вид», «Показ» —
  бейджи `ui.label`. Таблица и форма — в карточках.
* Подписи и цвета бейджей, набор кнопок — чистая `Announce\ListView::row()`,
  тест `tests/listview_test.php`. Экранирование, sessid и права — как были.
* Пункт меню «Настройки» — сразу под «Избранным»: `sort` 60 (у «Избранного»
  50, у «Пользователей» 100, `main/admin/menu.php`; было 1750).
* Название с префиксом: «[SH] Оповещения для сотрудников» — пункт меню (он же
  хлебные крошки), заголовок страницы (`Constants::TITLE`), вкладка и ссылка на
  странице настроек модуля.

## 1.2.0 — 2026-10-17

* Убран перенос из `shef.toolsai`: на обоих порталах модуль стоит, данные
  перенесены. Нет больше `Main\Migration`, сообщения «Перенесено из
  shef.toolsai…» после установки, `Constants::LEGACY_MODULE_ID`,
  `Announcements::mergeSeen()` и `migrateOption()`.
* Отметки «видел» — только своя категория: старая `shef.toolsai` /
  `announce_seen` не читается, «Показать мне снова» снимает отметку только у
  себя.
* Установка больше не снимает старый `main:OnEpilog` `shef.toolsai`. Ставить
  модуль на портал с `shef.toolsai` до 1.50.0 — через 1.1.0.
* Чтение старого формата тестовых пользователей «1,15» оставлено: проверить,
  что на порталах значение пересохранено в JSON, нечем, а без него тестовые
  объявления молча перестанут приходить.

## 1.1.0 — 2026-10-17

* Модуль называется «[SH] Оповещения для сотрудников» (было «Новинки для
  сотрудников»): название модуля, страница списка, пункт меню, вкладка
  настроек, документация. Коды настроек, отметок и события не менялись.
* Место в списке решений: `MODULE_SORT` 1004 (было 1011) — после
  `shef.haschangefiles`, перед `shef.toolsai`.
* «Тестовые пользователи» выбираются штатным окном выбора сотрудников
  (`Shef\Options\Main\Options\Department`, только сотрудники, без «все
  сотрудники»); значение — JSON-список, по умолчанию — администратор (ID 1).
  Старое «ID через запятую» (на портале уже сохранено `1`) читается как
  раньше, а на странице настроек показывается переведённым в JSON с именами
  (`Main\TestUsersOption`, наследник Department) — что видно в выборе, то и
  работает; при сохранении в базу ложится JSON. Установщик для этого не
  нужен: деплой копирует файлы без него.
* Перенос из `shef.toolsai` не тронут.

## 1.0.1 — 2026-10-16

* Установка снимает старый обработчик новинок `shef.toolsai`
  (`main:OnEpilog` → `Shef\ToolsAi\Announce\Events::onEpilog`, оба написания
  класса): на `shef.toolsai` старше 1.50.0 окно больше не показывается дважды.

## 1.0.0 — 2026-10-16

Первая версия: «Новинки для сотрудников» вынесены из `shef.toolsai` (1.31.0–1.49.x)
в отдельный модуль. Для сотрудника ничего не меняется: то же окно, та же
аудитория, те же отметки «видел».

* Событие `shef.toolsaiannounce:OnAnnouncementsCollect`: модули отдают свои
  объявления; свой список из настроек заменяет объявление с тем же id,
  конфликты id между модулями — в лог `shef.problems`.
* Своя страница списка `/bitrix/admin/shef_toolsaiannounce_list.php` (пункт
  «Настройки → Новинки для сотрудников»), тестовые пользователи — на странице
  настроек модуля. Права — уровни модуля: R смотреть, W править.
* Отметка «видел» — действие `shef:toolsaiannounce.banner.seen` (было
  `shef:toolsai.kb.seen`).
* Установщик: подписка `main:OnEpilog`, снятие при удалении; перенос из
  `shef.toolsai` настроек `ANNOUNCE_list`, `ANNOUNCE_testusers` (если свои
  пусты) и отметок «видел» всех пользователей.
* Модули зовутся по одному — сбой одного обработчика не гасит остальные;
  итоговый список кешируется на 10 минут, сброс при сохранении.
* Отметки «видел» из `shef.toolsai` читаются вместе со своими, пока они есть.
* Вид «слайды»: заголовок экранируется (ядро вставляет его через innerHTML).
* Объявления «ИИ в звонках» в модуле больше нет — его присылает `shef.toolsai`
  через событие.
