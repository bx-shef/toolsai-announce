# shef.toolsaiannounce — «Оповещения для сотрудников»

Модуль коробочного Битрикс24. Показывает сотруднику **один раз** окно с
новинкой: что появилось, зачем и кнопка «Подробнее». Где показывать — у
каждого объявления своё (по умолчанию — CRM). Закрыл — больше это объявление
не появится (или снова — если так настроен повтор).

Зачем отдельным модулем: раньше новинки жили внутри `shef.toolsai`
(ИИ-инструменты). Теперь объявления может прислать **любой модуль** — через
событие `shef.toolsaiannounce:OnAnnouncementsCollect`, — а администратор правит
и выключает их на одной странице.

## Что умеет

* «Где показывать» — места на выбор (вся CRM, сделки, лиды, вид «ИИ»…) или
  своё начало адреса с параметрами; по умолчанию `/crm/`. Только в основном
  окне, не в слайдере карточки; встаёт в общую очередь окон Битрикс24.
* Виды: обычное окно, «важное» (закрыть — только кнопкой), предупреждение,
  поздравление, обучающее видео (YouTube, Rutube, VK Видео, .mp4) и штатные
  слайды «Что нового». Своя картинка вместо стандартной.
* Аудитория: «тестовые пользователи», «все сотрудники» или выбранные
  сотрудники и отделы. Новым сотрудникам (пришли после публикации) новости
  не показываются, если не включено «и новым».
* Период показа, порядок, повтор (один раз / пока не нажмёт «Понятно» / раз в
  N дней), цвет главной кнопки.
* «Показать мне снова» — снять у себя отметку «видел».
* Объявления других модулей — в том же списке, с источником. Свою копию можно
  сохранить вместо модульной: так объявление правят или выключают.

## Зависимости

`shef.options` 3.0+ и `shef.problems` 2.0+. От `shef.toolsai` модуль **не
зависит** (перенос данных оттуда выполнен и убран в 1.2.0).

## Установка

Composer (`bxshef/toolsai-announce`, тип `bitrix-module`, каталог
`bitrix/modules/shef.toolsaiannounce`) или архив `./build.sh`. Затем —
«Настройки → Настройки модулей → [SH] Оповещения для сотрудников → Установить».
